# toolbelt

68 small everyday utilities in one page: count characters, diff two files, format JSON, decode a
JWT, hash a file, convert a timestamp, explain a cron expression, check a color contrast… Everything
runs in your browser. There is no server and no tracking, nothing you type leaves the tab, and once
loaded it works offline. English and French.

**→ [maxgfr.github.io/toolbelt](https://maxgfr.github.io/toolbelt/)**

## How it feels

- **⌘K / Ctrl+K** jumps to any tool by name, in English or French (`diff`, `compter`, `sha`…).
- **Files**: drop a file on any text box, or open one; results can be copied or downloaded.
- **Your input stays**: each tool remembers what you typed (in your browser's storage), except
  secrets: passwords, keys, tokens and `.env` files are never stored.
- **Share a link**: the link button puts the tool's input in the URL fragment, compressed. The
  fragment is never sent to a server; whoever opens the link sees the same input.
- **Favorites and recent tools** on the home page, light and dark themes, installable as an app.

## Privacy

The page is served with a Content-Security-Policy that allows no request outside the site
(`connect-src 'self'`), no inline script and no third-party code; the build fails if the page
references another origin. Each tool is its own chunk, loaded when you open it, and a service
worker keeps them all for offline use. The end-to-end tests open every tool in both languages and
fail on any request that leaves the site.

## Develop

```bash
bun install
bun run dev        # http://localhost:5173/toolbelt/, rebuilt on change
bun run test       # unit tests (the logic of every tool)
bun run test:e2e   # Playwright: every tool in EN and FR, plus real round trips
bun run lint && bun run typecheck
bun run build      # dist/, deployed to GitHub Pages by .github/workflows/pages.yml
```

Adding a tool is three files and a registry entry; see [AGENTS.md](AGENTS.md).

Stack: Bun, TypeScript, Preact with signals, and for some tools jsdiff, yaml, smol-toml,
Papa Parse, sql-formatter, cronstrue, croner, ua-parser-js, culori, hash-wasm, marked, DOMPurify,
Turndown, qrcode-generator and jsQR. MIT license.
